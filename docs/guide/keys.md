---
title: Keys
description: Every ytui keyboard shortcut for browsing, playback, volume, captions and the picture.
---

Press `?` in ytui to see these at any time. The mouse works too: click anything, scroll with the wheel, and click
the progress bar to seek.

## Browsing

| Key | What it does |
|---|---|
| `/` or `Ctrl-L` | Search, or open a URL |
| Arrows or `hjkl`, `Enter` | Move, open |
| `g` or `Home`, `End` | Go to the top, the bottom |
| `H` / `L` | Back, forward |
| `Ctrl-T`, `Ctrl-W` | New tab, close tab |
| `J` / `K` | Next tab, previous tab |
| `t` | Open in a new tab |
| `w` `s` `c` | Watch later, subscribe, go to the channel |
| `P` | Save the video to a playlist |
| `@` | Sign in |

## Playback

| Key | What it does |
|---|---|
| `space` | Pause and play |
| `f` | Fullscreen |
| `,` `.` | Seek back or forward 10 seconds |
| `<` `>` | Seek back or forward 60 seconds |
| `0`–`9` | Jump to 0%–90% of the video |
| `+` `-` `M` | Volume up, down, mute |
| `S` | Captions: your language first, then each track, then off |
| `n` `a` `x` | Next video, autoplay on or off, close the player |
| `C` `I` | Show or hide live chat, send a chat message |

## Picture

| Key | What it does |
|---|---|
| `E` | Auto-exposure on or off |

## Writing comments and chat

| Key | What it does |
|---|---|
| `Enter` | Post |
| `Alt-Enter` | New line |
| `Esc` | Cancel |

Pasting works.

`q` quits.
