Watch YouTube in the terminal

ytui is a free, open-source YouTube client for your terminal. You can search, browse Home and Trending, and play videos as ASCII art or real pixels at up to 60 fps. It runs on Windows, Linux and macOS, with no browser and no API key.

Install

Download the package for your system from the latest release, then install the tools ytui plays through. The step-by-step guide to watching YouTube in the terminal walks through each system, SSH and tmux.

Windows 10 and 11

Unzip and run ytui.exe in Windows Terminal. libmpv is included.

winget install yt-dlp.yt-dlp Gyan.FFmpeg DenoLand.Deno

macOS (Apple Silicon)

Extract the archive and run ytui from your terminal.

brew install yt-dlp ffmpeg deno mpv

Linux (x86_64)

Install yt-dlp, ffmpeg, Node.js 22+ or Deno, and libmpv with your package manager. Or build from source:

cargo build --release

Pick how video looks

Press m to cycle the character modes. Press G for pixel graphics and N for the native window. Press o to tune the picture.

YouTube's layout, in a terminal

Home, Trending and categories
Music, Gaming, News, Live, Sports, Learning, Podcasts and Movies, as a thumbnail grid you can click.
Search, channels and playlists
Press / to search or paste a URL. Open channels, playlists, comments and live chat.
60 fps playback through libmpv
Hardware decoding, seeks in about a tenth of a second, instant pause and A/V sync. It falls back to ffmpeg when libmpv isn't installed.
Captions
Press S to cycle caption tracks. Your language choice is remembered for later videos.
Optional Google sign-in
See your recommendations, subscriptions and playlists, and like and comment. Signing in also keeps videos playing when YouTube asks you to "confirm you're not a bot".
Works over SSH and in tmux
Character modes run in any truecolour terminal. tmux without truecolour gets dithered 256-colour output.

Questions

How do I watch YouTube in the terminal?

Download ytui from the releases page, install yt-dlp and ffmpeg, and run ytui. It opens YouTube's Home page in your terminal. Press / to search and Enter to play a video. You can also start with a search, like ytui lofi hip hop, or with a video URL.

Does ytui need a YouTube account or API key?

No. Searching, browsing and watching work signed out, with no API key. Signing in with Google is optional. It adds your recommendations, subscriptions, playlists, likes and comments.

Which terminals show real pixels?

Terminals with sixel (Windows Terminal, WezTerm, foot, xterm, mlterm, Konsole) or the kitty graphics protocol (kitty, Ghostty), including inside tmux. Every other truecolour terminal gets ASCII art or Unicode mosaics.

Does it work over SSH?

Yes. The character render modes work in any truecolour terminal, so you can watch over SSH. Audio is off by default over SSH; choose an output with --audio. See watching YouTube over SSH.

Is there a YouTube TUI for Windows?

Yes. ytui runs natively on Windows 10 and 11 in Windows Terminal, with sixel graphics, WASAPI audio and a native GPU video window. The Windows download includes libmpv.

How is ytui different from ytfzf or youtube-tui?

ytfzf and youtube-tui help you find a video in the terminal, then usually hand it to mpv in a separate window. ytui plays the video inside the terminal itself, as ASCII art, Unicode mosaics, sixel or kitty graphics, in a YouTube-style interface with Home, channels, comments and live chat. See terminal YouTube clients compared.

Is ytui free?

Yes. ytui is free and open source under the MIT licence.
